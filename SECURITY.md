# Security / 安全反馈

Please do not publish a suspected vulnerability, private key, seed phrase, or personal information in a GitHub issue. Contact the project through the official links on [bitbt.fun](https://bitbt.fun) and include the affected page or contract address, impact, and reproduction steps. Verify the official contact channel on the website before sharing sensitive details.

请勿在 GitHub Issue 中公开漏洞细节、私钥、助记词或个人资料。请通过 [bitbt.fun](https://bitbt.fun) 官网列出的官方渠道联系项目，并说明受影响页面或合约地址、影响和复现步骤。
